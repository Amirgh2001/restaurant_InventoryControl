# سامانه هوشمند مدیریت موجودی و انبارداری رستوران (Restaurant Inventory Control System)

یک سیستم جامع، سریع، بدون خطا و بهینه‌سازی شده برای محیط‌های شلوغ و عملیاتی رستوران، فست‌فود و آشپزخانه‌های صنعتی.

---

## 🎯 ویژگی‌های برجسته سیستم

1. **طراحی دوفازی (مدیران دقیق / کارکنان ساده):**
   - **پنل لمسی پرسنل (Touch-First UX):** رابط کاربری بزرگ، آیکون‌دار، کاملاً فارسی و راست‌به‌چپ (RTL)، دارای کالاهای پرمصرف با یک لمس، کیپد عددی لمسی اختصاصی (On-screen Numpad) بدون نیاز به تایپ طولانی.
   - **داشبورد تحلیلی مدیریت:** ماتریس موجودی چند مکانه، هشدارهای کمبود، گزارش تفکیکی ضایعات، ردیابی تاریخچه عملیات، انبارگردانی و مغایرت‌گیری و خروجی اکسل با استایل کامل فارسی.

2. **مدیریت انبارها و مکان‌های چندگانه:**
   - سردخانه یا انبار اصلی (MAIN_COLD)
   - یخچال انبار در مجموعه سرویس‌دهی (SERVICE_FRIDGE)
   - لاین آماده‌سازی و تولید محصولات (PREP_LINE)
   - امکان افزودن بی‌نهایت مکان و انبار جدید.

3. **عملیات ۶ گانه انبارداری (با کنترل تراکنش اتمیک ACID):**
   - **📥 ورود کالا:** افزایش موجودی، امکان درج شماره فاکتور/بچ و انقضا.
   - **🔄 انتقال بین بخش‌ها:** کسر اتمیک از مبدأ و افزایش در مقصد (جلوگیری از انتقال تکراری یا مغایرت).
   - **🍳 ثبت مصرف:** کسر مواد اولیه از خط تولید با بررسی موجودی لحظه‌ای.
   - **🗑️ ثبت ضایعات:** کسر از موجودی با الزام انتخاب دلیل (فساد و بو، خطای پخت و سوختگی، انقضا، ضربه‌دیدگی/ریختن).
   - **🔍 انبارگردانی و اصلاح مغایرت:** ثبت شمارش واقعی فیزیکی، محاسبه خودکار اختلاف (کسری/اضافی)، و اصلاح اتمیک موجودی پس از تأیید مدیر.
   - **📜 دفتر کل و تاریخچه غیرقابل تغییر (Audit Trail):** ثبت دقیق اینکه چه کسی، در چه تاریخی، چه کالایی را به چه مقداری در کدام بخش جابجا کرده است.

4. **جلوگیری از خطای انسانی و امنیت داده‌ها:**
   - **ممنوعیت موجودی منفی:** سیستم به صورت سخت‌گیرانه در سمت سرور مانع از ثبت مصرف یا انتقال فراتر از موجودی واقعی می‌شود.
   - **تبدیل هوشمند واحدها:** امکان ثبت به گرم و تبدیل خودکار به کیلوگرم واحد پایه، یا عدد به بسته/کارتن.
   - **سطوح دسترسی (RBAC):** اعمال مجوزها هم در کلاینت و هم در سرور با توکن‌های امن HMAC-SHA256.

## 🚀 راهنمای راه‌اندازی و اجرا

این پروژه بدون هیچ‌گونه نیاز به نصب پکیج‌های خارجی سنگین یا اتصال به اینترنت، با پایتون ۳ استاندارد اجرا می‌شود:

```bash
# راه‌اندازی با پورت پیش‌فرض ۸۰۸۰
./run.sh

# یا انتخاب پورت دلخواه مثلا ۹۰۰۰
./run.sh 9000
```

سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://localhost:8080`**

## 👥 حساب‌های کاربری پیش‌فرض سیستم

در صفحه ورود می‌توانید با نام کاربری و رمزهای زیر وارد شوید، یا با **دکمه‌های ورود سریع تک‌کلیکی** هر نقش را فوراً آزمایش کنید:

| نقش کاربری | نام کاربری | رمز عبور | دسترسی‌ها |
| :--- | :--- | :--- | :--- |
| **مدیر مجموعه** | `admin` | `admin123` | دسترسی کامل به تمام بخش‌ها، تأیید انبارگردانی، گزارش‌ها، ثبت کالا، خروجی اکسل و تعاریف |
| **سرپرست شیفت** | `supervisor` | `sup123` | ثبت کالای جدید، نظارت بر بخش‌ها، ثبت عملیات، ثبت انبارگردانی و مشاهده گزارش‌های بخش |
| **اپراتور لاین/آشپزخانه** | `operator` | `op123` | پنل فوق‌العاده ساده لمسی صرفاً جهت ثبت ورود، انتقال، مصرف و ضایعات |
| **مسئول انبارگردانی** | `auditor` | `audit123` | شمارش موجودی واقعی و ثبت مغایرت‌ها |
| **مدیر فناوری و سیستم** | `sysadmin` | `sys123` | مدیریت کالاها، انبارها، کاربران و نقش‌ها |

## 🧪 اجرای تست‌های خودکار

برای اطمینان از سلامت تراکنش‌ها و منطق تجاری:

```bash
PYTHONPATH=. /usr/local/bin/python3 tests/test_inventory.py
PYTHONPATH=. /usr/local/bin/python3 tests/test_api_endpoints.py
```
*(تمامی ۱۱ تست یکپارچگی، تبدیل واحدها، جلوگیری از منفی شدن موجودی و خروجی اکسل با موفقیت ۱۰۰٪ پاس شده‌اند).*

## 📁 ساختار فایل‌های پروژه

```
ctrlMojoodi/
├── app/
│   ├── database.py          # اسکیما SQLite، تراکنش‌ها، هش رمز و سید داده‌های رستوران
│   ├── auth.py              # احراز هویت، توکن امن HMAC و کنترل دسترسی مکانی/نقشی (RBAC)
│   ├── inventory_service.py # منطق تجاری: ورود، انتقال اتمیک، مصرف، ضایعات، انبارگردانی
│   ├── reports_service.py   # ماتریس موجودی، تحلیل ضایعات، ردیاب غیرعادی و خروجی اکسل (XLSX)
│   └── server.py            # وب‌سرور چندریسمانی (Threading) و REST API استاندارد
├── static/
│   ├── index.html           # کلاینت SPA راست‌به‌چپ (RTL) بهینه موبایل و تبلت
│   ├── app.js               # منطق کامل کلاینت، کیپد لمسی، فیلترها و مودال‌ها
│   └── styles.css           # طراحی واکنش‌گرا با دکمه‌های بزرگ لمسی
├── tests/
│   ├── test_inventory.py    # تست‌های تراکنش انبار، جلوگیری از موجودی منفی و تبدیل واحد
│   └── test_api_endpoints.py# تست‌های API، گزارش‌ها و فایل اکسل
├── inventory.db             # پایگاه داده SQLite
├── run.sh                   # اسکریپت راه‌اندازی سریع
└── README.md                # مستندات کامل سیستم
```
